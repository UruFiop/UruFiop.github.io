Astro 6.x の Content Collections

Astro 6.x からは loader API を使うことで、より柔軟にコンテンツを管理できるようになっています。

const tech = defineCollection({
  loader: glob({ pattern: "**/*.md", base: "./src/content/tech" }),
  schema: z.object({
    title: z.string(),
    pubDate: z.date(),
    description: z.string().optional(),
    tags: z.array(z.string()).optional(),
  }),
});
